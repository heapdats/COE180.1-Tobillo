Multiplexers in Combinational Logic Design LAB 3.

o Objectives: What was the goal of this lab?

■ Understand the fundamental concept and functionality of
multiplexers as data selectors in digital circuits.
■ Design and implement multiplexers using Verilog HDL with
different modeling styles.
■ Write comprehensive testbenches to verify multiplexer
functionality.
■ Compile and simulate Verilog designs using Icarus Verilog.
■ Analyze simulation waveforms in GTKWave to verify circuit
operation.
■ Build higher-order multiplexers using smaller multiplexer
components.


o Design Description: 
We made 2:4, 3:8, and 4:16 Multiplexers using verilog code using Dataflow, Behavioural, and Structural design
